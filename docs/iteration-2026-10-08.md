# TabTasks 0.5.0 迭代说明

免费版支持 30 个活动任务、2 个列表、网页和选区收集、备注、子任务、到期日及日历导出。Pro 支持无限活动任务和列表、标签、可读取网页的摘要、JSON 备份及可选 AI 助手。AI 支持 OpenAI Chat Completions 与 Anthropic Messages 兼容接口，可自定义服务地址、模型和 API Key；包含 OpenAI、Anthropic、DeepSeek 预设。免费版可配置并测试连接。

- 付款后自动激活，等待状态可重试并保存在本机；后台核对真实订单，不依赖成功页 URL 直接授予 Pro。
- 独立升级面板，设置中仅保留简明 Pro 卡片。备用授权码折叠，AI API Key 与 Pro 授权码名称分开。
- 邮箱验证码恢复代码已实现，须配置发件服务。原签名与旧存储键保留。
- 英文与简体中文文案同步；320／360／400／640px 布局验证。

测试使用模拟付款、邮件与 AI 数据；未真实扣款或调用收费模型。此次源码不代表已上线 Worker 或已提交 Chrome 商店，发布顺序见 worker/DEPLOY.md。
