# TabTasks 0.6.0 商店文案

## English

Capture webpages and selected text as tasks in your browser sidebar. Free includes 30 active tasks and 3 custom lists, plus notes, tags, dates, subtasks, page excerpts, JSON backups and calendar export. Built-in lists and completed tasks do not use those quotas.

Reuse one flow template with relative dates and save one smart view for free. Pro adds more templates, project-name variables, cross-list flows, batch starts, saved views with grouping and multi-task AI planning with reusable instructions.

Connect an OpenAI Chat Completions or Anthropic Messages compatible service using your API key, address and model. Single-task AI is free. Only selected task titles, dates, completion state and tags are sent with your instruction; URLs, notes and excerpts are excluded. Preview, select and confirm changes. API usage is billed by your chosen provider and is not included in Pro.

Three free text sizes; browser language by default, English fallback, manual English/Simplified Chinese. Local data, no extension usage analytics. Pro is a $6 one-time purchase, with applicable tax shown at checkout. Purchases started in the extension activate automatically, with email recovery and existing license support.

## 简体中文

免费保留 30 个活动任务、创建 3 个自定义列表，内置列表与已完成任务不占对应额度。基础标签、短摘录、备注、日期、子任务、JSON 备份和日历导出开放。免费可反复使用一个流程模板、保存一个智能视图并使用单任务自带 Key AI。Pro 增加多模板、变量、跨列表和批量启动、组合视图分组与多任务 AI 计划。AI 支持 OpenAI / Anthropic 兼容接口，发送你选择的任务及已披露字段，逐项确认应用，调用费用由所选服务商另行收取。

免费提供紧凑、标准、大字；默认跟随浏览器语言，识别失败或未支持时使用英文，也可手动选择。数据保存在本机，插件内不收集使用统计。Pro 每款 $6 一次性买断，适用税费以结账页为准；从插件发起购买后自动激活，支持邮件恢复和已有授权码。
