Before you start

Is my content synced to a cloud?

No. Content and reusable workflows stay in this browser. JSON backups are available on Free; export before changing devices or uninstalling. Credentials and Pro licenses are excluded. The extension has no usage analytics; website traffic analytics is separate.

Which AI services can I use, and who pays?

Choose an OpenAI Chat Completions or Anthropic Messages compatible service, API address and model. Compatibility depends on the provider implementation. Use your own API key; API usage is billed by that provider and is not included in Pro. A consumer chat subscription does not necessarily include API access.

How does a Pro purchase work?

Each product has an optional $6 one-time Pro purchase, with applicable tax shown at checkout. Purchases started in the extension support verified automatic activation. For another device, use purchase-email recovery or an existing license code.

LOCAL FIRST

Your workspace stays local.

Tasks, templates and views stay local. AI sends only your instruction and selected task IDs, titles, dates, completion states and tags to your chosen service; URLs, notes and page excerpts are excluded. No extension usage analytics.
