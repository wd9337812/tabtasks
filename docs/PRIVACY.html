English

TabTasks is a browser side-panel to-do & page-capture extension. We do not sell your data or upload task content to developer servers. Only an explicit AI request sends the task snapshot described below directly to OpenAI.

What data exists, and where does it live?
Everything you create in TabTasks — task titles, page links you capture, page text excerpts you choose to save, list names, tags, and due dates — is stored only in your own browser via the chrome.storage API. Optional AI and exports process selected data as described below. Uninstalling the extension (or explicitly clearing extension storage) deletes your local data. We have no server that stores task content.

Why does the extension request broad permissions?
TabTasks reads the title and URL of the page you are actively viewing, and (if you are a Pro user) a short text excerpt, only when you request capture through a button, shortcut or selection menu. That information is written to local storage. Capture itself does not send task content to a server; a later explicit AI request sends only the snapshot described below.

Licensing & payments.
Pro is an optional one-time purchase through Stripe-hosted checkout. Before creating a checkout order, our purchase page explains the order data processing and asks you to agree and continue. Full card numbers and CVC are handled by Stripe. Our Cloudflare Worker creates the checkout and verifies its payment status through Stripe's API and signed webhooks. Each product has a separate Cloudflare D1 order database storing order, Checkout Session, PaymentIntent, product, price and event identifiers; amount, currency, payment/refund and license-delivery status; and timestamps. These records support license delivery, recovery and payment support. We do not store card details, checkout email addresses, billing addresses, raw webhook bodies, extension tasks or saved tab sessions in that database. The extension verifies the issued license locally. No usage telemetry is sent to the developer.

Order retention & your requests.
Order records are retained for license recovery and payment support; uninstalling the extension does not delete those server records. To request access, correction or deletion, contact the developer privately through the contact details on the GitHub profile. Do not publish order references or license keys in public issues. Deleting our order records does not delete Stripe's separate payment records and can affect license recovery. There is no automatic order-retention expiry at present. Stripe and Cloudflare process payment and service requests under their own policies: Stripe privacy and Cloudflare privacy.

Optional AI assistant (bring your own key).
The AI assistant is off by default and never contacts any server unless you enable it and paste your own OpenAI API key into the extension. When you use it, the task titles, IDs, due dates, completion state and tags, plus your instruction goes directly from your browser to api.openai.com under your key, and OpenAI's own privacy terms apply to that request. The key is stored only in your local chrome.storage, is never sent to us, and can be removed at any time from the settings drawer. Right-click selection capture and .ics calendar export are fully local and involve no network access.

Privacy policy for the Chrome Web Store listing: this extension stores tasks locally. Optional AI transmits task titles, IDs, due dates, completion state, tags and your instruction to OpenAI; notes, page URLs and page excerpts are not included in the AI snapshot. The optional host permission applies only to api.openai.com. API usage may incur charges under your OpenAI account.

Contact: open an issue at https://github.com/wd9337812/tabtasks or email the developer via the GitHub profile.

中文

TabTasks 是一款浏览器侧边栏待办与网页收集扩展。我们声明： 本扩展不出售用户数据，不向开发者服务器上传任务内容。仅在你点击 AI 发送时，将下述任务快照和指令直连发送给 OpenAI。

数据存在哪里？
你在 TabTasks 中创建的一切内容——任务标题、收集的网页链接、保存的正文摘要、 列表名称、标签与到期日——仅通过 chrome.storage 存储在你自己的 浏览器本地；仅在你主动使用 AI 助手或导出备份时按相应功能处理。卸载扩展（或明确清除扩展存储）即永久删除。 我们没有存放任务内容的服务器。

为什么申请较宽的权限？
仅在你主动点击收集、使用快捷键或右键选区时，扩展会读取当前页面的标题、网址， （Pro 用户）以及一小段正文摘要，并写入你的本地存储。收集动作本身不向服务器发送任务内容； 之后主动使用 AI 时，仅发送下文说明的快照。

许可与支付。
Pro 为可选的一次性买断，通过 Stripe 托管结账页付款。创建结账订单前，购买页会说明订单数据处理方式，由你点击同意后继续。完整卡号和 CVC 由 Stripe 处理。我们的 Cloudflare Worker 创建结账订单，通过 Stripe API 与经过签名验证的付款回调核对状态。两个商品各自使用独立的 Cloudflare D1 订单数据库，保存订单、Checkout Session、PaymentIntent、商品、价格与回调事件编号，金额、币种、付款／退款和授权签发状态，以及时间，用于授权签发、Key 找回和付款支持。该数据库不保存银行卡信息、结账邮箱、账单地址、原始回调内容、扩展任务或保存的标签会话。扩展在本机校验授权；不向开发者发送使用遥测。

订单保存与数据请求。
订单记录保留用于授权找回与付款支持；卸载扩展不会删除这些服务器记录。需要查询、更正或删除时，请通过 GitHub 个人主页的联系方式私下联系开发者，勿在公开 Issue 发布付款编号或授权 Key。删除我们的订单记录不会删除 Stripe 独立保存的付款记录，并可能影响授权找回。目前没有自动清理订单的到期机制。Stripe 和 Cloudflare 按各自的隐私政策处理付款及服务请求：Stripe 隐私政策、Cloudflare 隐私政策。

可选 AI 助手（自带 Key）。
AI 助手默认关闭：除非你主动开启并粘贴自己的 OpenAI API Key，扩展不会联系 任何服务器。使用时，任务标题、ID、到期日、完成状态、标签及你的指令（不包含任务备注、网页链接和正文摘要）由你的浏览器直连 api.openai.com，该请求受 OpenAI 自身隐私条款约束。API 调用可能产生你自己的 OpenAI 账户费用；联网权限仅限 api.openai.com。Key 仅存于本机 chrome.storage，不会发给我们，可随时在设置抽屉中删除。 右键选区捕获与 .ics 日程导出完全在本地完成，不产生任何网络请求。

联系方式：https://github.com/wd9337812/tabtasks 提交 Issue， 或通过 GitHub 主页邮箱联系开发者。
