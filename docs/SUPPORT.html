🔑 License & billing / 激活与付款

  • After payment, copy your License Key from the confirmation page into Settings → Activate Pro. Keep that page’s address to retrieve the key again. License keys are not automatically emailed.
    付款后从成功页复制 License Key，在设置中激活 Pro；保留成功页地址可重新领取。授权 Key 不会自动通过邮件发送。
  • Lost your key? Contact the developer privately using the contact details on the GitHub profile. We can check the order and retrieve the key. Do not publish payment references or license keys in public issues.
    Key 丢失时请通过 GitHub 主页联系方式私下联系我们核对订单；勿在公开 Issue 发布付款编号或授权。
  • Refunds: email us within 14 days, no questions asked.
    14 天内可无理由退款。

❓ Quick fixes / 常见问题

  • Sidebar missing → click the TabTasks toolbar icon, or right-click → "Show TabTasks in side panel".
  • Shortcut not firing → chrome://extensions → Keyboard shortcuts → re-assign Alt+Shift+T.
  • All data is stored locally in your browser; uninstalling the extension without exporting deletes your tasks. Pro users can export a JSON backup from the footer.
