TabTasks — Support 支持中心

Updated / 生效日期：2026-10-09

English

Open and update

Click the toolbar icon. Chrome 116+ is required. Update the existing extension without uninstalling, which deletes local content. Alt+Shift+T collects the active page.

Activate or restore Pro

Use Settings → Explore Pro to buy. Purchases started inside the extension activate automatically after verified payment. If you closed checkout, open the panel and check payment status; avoid paying again. In purchase management, Restore purchase verifies the checkout email. If email recovery is not configured, use Have a license code? with your saved code or contact support privately. Website purchases and older extension versions can use the fallback code.

Local backups

JSON task backups require Pro. API keys are excluded. Use Export before uninstalling or moving devices.

Connect an AI service

Settings offers OpenAI, Anthropic, DeepSeek and Custom. Choose the API format, service address, model and your service’s API key; Test connection is available on Free. Model/API access is separate from a consumer chat subscription. Pro AI usage is charged by your service. If a model/endpoint is missing, check the provider’s exact address and model ID. HTTP is allowed only for local loopback models.

Refunds

Request a full refund within 14 days of purchase using your Stripe receipt, through the developer’s private contact on GitHub. Older purchases are handled case by case. Refunds prevent new server license retrieval; already activated offline licenses are not automatically revoked.

Contact

GitHub issues for public bugs; use the developer’s GitHub profile contact for orders. Never publish API keys, license codes or checkout references. Replies within 2 business days.

中文

打开与更新

点击工具栏图标，需要 Chrome 116+。直接更新原扩展；卸载会删除本地内容。Alt+Shift+T 收集当前网页。

激活与恢复购买

在设置 → 了解 Pro 中购买，确认付款后会自动激活。关闭付款页后也可返回插件检查付款状态，请勿重复付款。“管理购买”中的“恢复购买”通过结账邮箱验证码核实。若邮件服务暂未配置，可在“已有授权码？”输入保存的授权码，或私下联系支持。从网站购买及旧版插件可使用备用授权码。

本地备份

任务 JSON 备份需 Pro，API Key 不进入备份。卸载或换设备前请先导出。

连接 AI

设置支持 OpenAI、Anthropic、DeepSeek 和自定义服务。填写接口协议、服务地址、模型与该服务的 API Key；免费版可测试连接。聊天产品订阅不等于 API 使用权限，Pro 不包含服务商调用费用。若找不到模型或接口，请核对服务商文档中的地址及模型 ID。HTTP 仅允许本机回环模型。

退款

购买后 14 天内可凭 Stripe 收据通过开发者 GitHub 主页联系方式申请全额退款；超过 14 天逐单处理。退款阻止服务器重新签发，已激活的离线授权不会自动撤销。

联系

公共问题可到 GitHub Issues；订单请通过 GitHub 主页私下联系。不要公开 API Key、授权码或付款编号。两个工作日内回复。
